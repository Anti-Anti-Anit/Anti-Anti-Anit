## ⚙️ How the auto-sync works

`.github/workflows/sync-profile.yml` runs every day (and on demand from the
**Actions** tab). It calls the GitHub API, renders the table between the
`repos:start` / `repos:end` markers above, and pushes a commit back to this
repo only when something actually changed.

**Force a refresh:** Actions → `sync-profile` → **Run workflow**
